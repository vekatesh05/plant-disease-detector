# PlantCare AI

AI-powered plant disease detection website frontend.

## Run locally

1. Install Python.
2. Open a terminal in this folder.
3. Run:
   `pip install -r requirements.txt`
4. Start:
   `python app.py`
5. Open:
   `http://127.0.0.1:5000`

The current version contains the complete responsive frontend and image upload/camera UI. The trained plant-disease model and prediction API can be connected next.
